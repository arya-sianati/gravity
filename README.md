# Gravity

**A live social activity map for discovering what people are actually doing around you.**

🌐 **Live:** https://gravity.college

Gravity was built for **MuleHacks 2026** around the theme of **Connections**.

> Social media shows you what people are posting. Gravity shows you what people are actually doing.

## What is Gravity?

Gravity helps people discover real-world activity happening around them right now.

Instead of posts, feeds, and status updates, Gravity focuses on actual activity:

- 🏀 Basketball
- 🏃 Running
- 📚 Studying
- 🏋️ Workout
- ⚽ Soccer
- 🎮 Gaming
- and dynamically configurable activities such as Pickleball

Users can start an activity, discover nearby sessions, join other people, scan QR codes, compete with friends, earn XP, and explore historical and predicted activity patterns around an area.

## Core Features

### 🗺️ Live Activity Map

Gravity uses MapLibre and PostGIS to visualize live activity as dynamic geographic heat.

Nearby sessions naturally combine visually while remaining separate sessions internally.

### 📡 Pulse Now

Discover what is happening nearby right now based on:

- distance
- number of active participants
- recency
- activity type

### 🔮 Pulse Soon

Gravity analyzes recurring historical activity patterns to show activity that is likely to happen nearby soon.

Forecasting is deterministic and explainable rather than generated by a black-box AI model.

It considers:

- recurring activity across weeks
- weekday
- time of day
- participation volume
- recency
- geographic clustering

### 🏛️ Gravity History

Inspect any geographic area and see:

- dominant activities
- historical participation
- busiest days
- peak activity times
- activity distribution

No manually defined venue or neighborhood objects are required.

### 🤝 Friends

Gravity supports mutual friendships with live activity presence and configurable location privacy.

### 🏆 Friend Challenges

Friends can compete through challenges such as:

- First to Target
- Highest Metric by Deadline
- Cooperative Combined Target

Metrics remain completely activity-configurable.

### ⚡ Gravity Events

Platform events can temporarily provide:

- XP multipliers
- bonus XP
- badges

### 🥇 Seasons & Leaderboards

Activity-specific seasonal competition using each activity's native metric.

Examples:

- Running → Distance
- Basketball → Points
- Studying → Duration
- Pickleball → Games Won

### ⭐ XP, Levels, Badges & Streaks

Gravity includes universal personal progression independent of activity-specific leaderboards.

### 📱 Progressive Web App

Gravity is an installable mobile-first PWA with:

- offline/degraded-state handling
- service worker
- safe-area support
- mobile navigation
- route-level code splitting
- app resume reconciliation

### 📷 QR Joining

Every active session can generate a QR code that lets another user quickly open and join the activity.

### 📍 Auto-Stop

Stationary activities can automatically stop when a participant leaves the activity area.

Movement-based activities such as Running are configured differently so moving away from the starting point does not incorrectly stop the activity.

## Privacy

Location privacy is built into Gravity's architecture.

Users can choose:

### Hidden

Live location is not shown to other users.

### Blurred

Other users see an approximate geographic area rather than the exact location.

### Friends

Accepted friends may see the exact activity location while other users receive a blurred location.

### Exact

Exact activity location is publicly visible.

Historical data and forecasts use aggregate geographic regions and minimum anonymity thresholds to prevent reconstruction of individual routines.

## Local Development

### Backend

Create a Python virtual environment and install the backend dependencies.

```bash
cd backend

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
```

Create your environment configuration based on the provided example.

Never commit the real `.env` file.

Run migrations:

```bash
python manage.py migrate
```

Start Django/ASGI using the development configuration documented in the project.

### Frontend

```bash
cd frontend

npm install
npm run dev
```

## Security

Production secrets are stored outside Git.

The repository must never contain:

- Django production secret keys
- database passwords
- `.env` files
- private TLS keys
- production database dumps
- authentication cookies or tokens
